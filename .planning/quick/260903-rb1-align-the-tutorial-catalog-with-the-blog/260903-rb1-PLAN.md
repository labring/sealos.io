# Quick Task 260903-rb1: Align the Tutorial Catalog with the Blog

**Status:** Ready

## Goal

Make `/tutorials/` visually belong to the existing Blog surface while keeping
the tutorial journey, framework opportunity matrix, request analytics, and
published Django entry intact.

## Tasks

### 1. Share the content-index heading pattern

- Add a small reusable content index heading component under `components/`.
- Refactor `BlogHeader` to use it with the existing Blog copy and RSS action.
- Use it on the Tutorial Catalog with its Django Core action.

### 2. Restyle and simplify the Tutorial Catalog

- Replace the custom full-screen hero background, screenshot, and statistic
  cards with the Blog page shell, `PageTopRays`, and a compact centered header.
- Keep the three-stage journey, simplify each card to intent, outcome, and its
  main entry, and move status counts into the matrix heading.
- Render the framework matrix as a flat editorial surface on desktop and a
  vertically stacked framework block on mobile.
- Keep request tracking on unavailable matrix cells and make the closing
  contact entry lightweight.
- Use Blog-aligned semantic tokens, borders, radii, and focus states.

### 3. Verify the surface

- Run the focused tutorial validation, TypeScript check, and production build.
- Verify `/tutorials/` and `/tutorials/django/deploy/` return HTTP 200 locally.
- Inspect desktop and mobile output for layout overflow and visible focus.

## Verification

`pnpm test` is unavailable in this repository; use the scripts and commands
listed in Task 3 plus the existing tutorial validation test.
