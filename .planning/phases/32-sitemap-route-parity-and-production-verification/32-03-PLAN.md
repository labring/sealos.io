|---|---|---|
| Count-valid stale deployed index passes a sitemap sample | high | Fetch live index and sitemap, compare all sets, crawl every index route. |
| Redirect following masks dead canonical routes | medium | `redirect: 'manual'`; direct HTTP 200 acceptance. |
| Hanging target stalls release indefinitely | medium | 10-second abort on every request and fixed eight-worker pool. |
| Retry storm amplifies production traffic | medium | One attempt per endpoint; whole-command rerun is operator-controlled. |
| Out-of-order completion corrupts evidence | medium | Position-indexed results and deterministic post-collection sorting. |
| Response body is fetched repeatedly for identity fields | low | One text read per direct 200 response. |
</threat_model>

## Performance Audit

- Exactly 2 index/sitemap requests, 2,000 page requests, and 2 invalid-route
  probes form the accepted remote pass.
- Eight workers bound simultaneous page requests.
- Ten seconds bounds each request; one pass has finite completion.
- Each page body is held only for extraction and then represented by compact
  result/finding data.
- Output detail is capped while totals remain complete.
