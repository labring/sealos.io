# Keep scenario hosting tutorials in the blog

Hosting tutorials that start from an environment the reader already owns — an
Ubuntu VPS, a Windows machine, or a Docker Compose host — publish under the
blog at `/blog/{scenario-topic}/`. The framework Tutorial Path at
`/tutorials/{framework}/{topic}/` stays reserved for learning paths that begin
with an application and end at a verified deployment. Scenario tutorials answer
environment questions from search and need the shorter blog URL; framework
tutorials need the durable framework namespace and the tutorial shell with its
entry paths and structured metadata.
